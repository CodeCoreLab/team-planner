# 团队协作台 · 使用说明

双击 `index.html` 即可使用。不需要安装、不需要运行任何程序、不联网。

---

## 第一次打开

1. 解压到一个**固定的文件夹**（建议桌面或文档里，不要放临时目录）
2. 双击 `index.html`（用 Edge 或 Chrome 打开）
3. 设置一个管理员密码（至少 6 位）
4. 点左下角「连接目录」，选中**刚才解压的这个文件夹**，点"允许"
5. 完成。之后每次改动都会自动写回文件夹里的 `data.js`

### 为什么要「连接目录」

浏览器出于安全考虑，网页不能随便改你硬盘上的文件。
点一次授权后它会记住，之后自动保存。若清理过浏览器数据，需要再点一次授权。

**不连接目录也能用**，但数据只存在浏览器里，换电脑或清理浏览器数据会丢失。
连接之后数据才会落成 `data.js` 这个文件，跟着文件夹走。

---

## 数据在哪

```
data.js   ← 你的全部数据，就在这个文件夹里
```

| 需求 | 做法 |
|---|---|
| **备份** | 复制整个文件夹，或只复制 `data.js` |
| **换电脑** | 把整个文件夹拷到新电脑，双击 index.html，数据自动载入 |
| **恢复误删** | 从备份复制 `data.js` 覆盖回来，重新打开 |
| **误清浏览器数据** | 重新打开 index.html，会自动从 data.js 恢复 |

> 换电脑后需要重新登录（这是正常的，浏览器会话不跨设备继承）。
> 登录页会提示"数据已载入"，说明数据完好，只是要重新输密码。

---

## 文件说明

```
index.html          程序入口（双击这个）
data.js             你的数据（连接目录后自动生成）
css/app.css         样式
js/                 程序代码（分层：core / data / io / ui / pages）
icons/              图标
使用说明.txt        本文档
```

**js 目录下任何一个文件都不能删**，删了会打不开（会显示"程序文件不完整"并说明缺哪个）。

## 支持的浏览器

| 浏览器 | 状态 |
|---|---|
| Edge / Chrome | ✅ 推荐，支持自动写回 |
| Firefox / Safari | ⚠️ 可用，但不能自动写文件（只能用「备份」手动导出） |

不支持 IE。极老的浏览器（Chrome 80 以下）可能无法运行。

## 主要功能

### 工作台
今日待办、完成率、逾期提醒、连续写日志天数、近期计划进度。

### 任务计划
- 五种视图：日 / 周 / 月 / 季 / 年，可前后翻页
- 按状态、优先级、负责人、标签、关键词筛选
- 任务可设：时段、开始/结束时间、跨天结束日期、优先级、负责人、协助人、标签、子任务、描述
- **循环任务**：设为每天/每周/每月会自动生成后续实例
- 看板拖拽改状态、拖拽排序、批量完成
- 导出 CSV（Excel 可直接打开）

### 工作日志
- 日报 / 周报 / 月报
- **一键汇总**：按当前周期自动把你的任务整理成文字
- 提交日历（近 5 周，色块显示哪天写过）
- 同一天同类型只保留一篇（再写就覆盖）
- 有权限的人可以点评（分一般/较好/优秀）

### 提醒中心
- 看板视图：待开始 / 进行中 / 已延期 / 已完成 四列
- 提醒清单：逾期 / 今天 / 即将到期分组
- 浏览器标签栏标题会显示逾期数量，一眼可见

### 统计报表
总体完成率、准时率、日报打卡率、近 8 周趋势、按部门、按成员。

### 组织架构
- 成员管理（新增/编辑/停用/删除/重置密码）
- 部门树（多级，有成员或子部门时不能删）
- 角色权限矩阵（8 个模块 × 6 种动作，数据范围可选仅自己/本部门/全部）

### 系统设置
站点名称、工作时段、工作日、每页条数、数据目录、备份导入、清空数据。

### 操作日志 / 回收站
记录谁在什么时候做了什么；删除的任务和日志可以在回收站恢复。

## 遇到问题

### 双击后什么都没发生

用**右键 → 打开方式 → Microsoft Edge** 试试。若还是不行，检查文件是否解压完整。

### 提示「程序文件不完整」

会告诉你是哪个文件缺失。常见原因：

- 解压不完整 → 重新解压整个压缩包
- 把 `index.html` 单独拷了出来 → 需要连同 `js`、`css`、`icons` 文件夹一起
- `js` 目录被改名

### 数据会不会丢

数据有三个层次，丢的概率很低：

1. 浏览器 IndexedDB（工作副本，实时写）
2. `data.js`（连接目录后自动写，覆盖前留 `data.bak.js`）
3. 你自己做的备份

最坏情况：浏览器数据被清理 **且** 没连接目录 **且** 没备份 → 会丢。
所以**强烈建议连一次目录**。

### 「保存到目录」提示失败

可能是授权过期。重新点左下角「连接目录」授权一次即可。

### 点备份后没反应

浏览器可能拦截了下载。检查地址栏右侧是否有拦截提示，允许后重试。

### 页面显示成乱七八糟的标签源码

说明文件版本不匹配（混用了不同版本的 js 文件）。重新解压完整的压缩包。

### 忘记密码

- 还有别的管理员账号 → 用它登录后在「组织架构」里重置
- 所有管理员密码都忘了 → 只能重新初始化（会清空数据），建议先备份 `data.js`

## 已知限制

- **单机使用**：数据在你自己电脑上，不支持多人协作
- **无系统托盘**：纯网页没有常驻进程，做不了托盘。需要用标签栏标题看逾期数
- **不发邮件**：没有服务端，原 SMTP 邮件提醒功能已移除
- **同时只能开一个标签页**：多标签页同时改同一份数据可能互相覆盖，建议只开一个
- **不支持 IE**：需要现代浏览器

---

## 从旧版本（exe 版）迁移

如果你之前用过 exe 版：

1. 打开 exe 版，进「系统设置」→「数据管理」→「导出备份」
2. 把得到的文件重命名为 `data.js`，放到本文件夹里
3. 双击 `index.html`，数据会自动载入

也可以直接从旧版的 `%LOCALAPPDATA%\TeamPlanner\app.db` 迁移，
但需要先用旧版导出成上面那个格式。
